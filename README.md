# Herv-Helps-Disabled
Hervé listens orders &amp; executes them on the computer. Aged people can speak, but cannot use a computer. Here it is. Hervé sees the screen, and clicks, double-click, scroll, fetches. He is a real human helping grandpa and grandma. Limitations : the whole project stopped due to ChatGPT limitations, these tasks do not fit with a LLM, based on text...
